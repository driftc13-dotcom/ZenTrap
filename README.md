# ZenTrap

Лаунчер Roblox (Electron). Дизайн и логика в одном проекте.

## Запуск
```
npm install
npm start        # запуск
npm test         # тесты логики (core/)
npm run dist     # установщик для Windows
```

## Структура
- `src/index.html` — весь интерфейс (лаунчер, вкладки, анимации, темы)
- `main.js`, `preload.js` — окно и связь интерфейса с логикой (IPC)
- `core/` — логика без привязки к интерфейсу:
  - `flags.js` — настройки -> Fast Flags. Пишутся ТОЛЬКО флаги из `allowlist.json`, значения проверяются
  - `allowlist.json` — встроенный снимок списка локально настраиваемых флагов Roblox; ZenTrap не загружает список из папки пользователя
  - `robloxSettings.js` — лимит FPS в общих пользовательских настройках Roblox (`GlobalBasicSettings_13.xml`)
  - `apply.js` — запись `ClientAppSettings.json` в `Versions\version-*\ClientSettings`
  - `store.js` — `Settings.json` (настройки, профили)
  - `robloxInstaller.js` — получение официальных пакетов Roblox, проверка целостности и установка в каталог ZenTrap
- `assets/` — логотип и иконка (SVG)

## Установка и удаление
- Windows-установщик позволяет выбрать каталог. В нём хранятся файлы ZenTrap и его собственная копия Roblox; настройки лаунчера лежат в подпапке `ZenTrapData`.
- При запуске ZenTrap проверяет версию Roblox и обновляет свою копию. Если рядом уже обнаружена версия Roblox без маркера ZenTrap, установка останавливается, чтобы не перезаписать чужие файлы.
- Fast Flags и Windows-параметры применяются к копии ZenTrap. Лимит FPS хранится в общем файле настроек Roblox и влияет на другие способы запуска под этой учётной записью.
- «Переустановить Roblox» заново скачивает и проверяет файлы только в каталоге, отмеченном `ZenTrap.Install.json`.
- Удаление лаунчера удаляет только версии Roblox из этого маркера и файлы ZenTrap. Другие версии Roblox и папки установок не сканируются и не затрагиваются.
- Для сборки установщика используйте `npm run dist`. Проверка сборки и загрузки Roblox в этой рабочей сессии не выполнялась.

## Правила безопасности
ZenTrap не меняет `RobloxPlayerBeta.exe` или DLL, не внедряется в процесс и не читает его память. Флаги выключены по умолчанию; при включении фильтруются по встроенному официальному списку, который Roblox может изменить. Это снижает риск вмешательства в клиент, но не является гарантией отсутствия санкций.

Панель FPS и пинга использует встроенную статистику Roblox и не перемещается. При включённой настройке сочетание `Ctrl+Alt+F8` отправляет официальную команду `Ctrl+Alt+F7` только когда Roblox — активное окно. ZenTrap не извлекает эти показатели из памяти игры.
